Una comparación da True o False

SímboloPreguntaCon nota = 3.5
==¿Es igual?nota == 5 → False
!=¿Es distinto?nota != 5 → True
>¿Es mayor?nota > 4 → False
<¿Es menor?nota < 4 → True
>=¿Mayor o igual?nota >= 3.0 → True
<=¿Menor o igual?nota <= 3.5 → True

El resultado es siempre un bool: True o False.

if / else

Tomar un camino u otro

Dibuja el diagrama de flujo en el tablero mientras lo explicas.

Un programa que decide

nota = 2.8
if nota >= 3.0:
    print("Aprobó")
else:
    print("Reprobó")

Como 2.8 no es mayor o igual a 3.0, la condición da False y el programa toma el camino del else.

El camino resaltado en azul es el que recorre el programa con nota = 2.8. Cambia el valor a 3.5 en vivo y pregunta qué camino toma ahora.

Anatomía de un if

if1 nota >= 3.02:3
    print("Aprobó")4
else:
    print("Reprobó")
  1. 1La palabra if (“si”, en inglés).
  2. 2La condición: algo que da True o False.
  3. 3Los dos puntos. Se olvidan mucho.
  4. 4La indentación: 4 espacios que marcan qué va dentro del if.
Lo que va dentro del if se corre solo si la condición es verdadera.
Muestra el olvido de los dos puntos antes de que ocurra: es el error más frecuente de la sesión. En Colab, la tecla Tab inserta los 4 espacios.

La indentación no es decoración

Sin indentación

if nota >= 3.0:
print("Aprobó")
IndentationError:
expected an indented
block after 'if'

Python no sabe qué va dentro del if.

if nota >= 3.0:
    print("Aprobó")

Sin dos puntos

if nota >= 3.0
    print("Aprobó")
SyntaxError:
expected ':'

Al if le faltan los : al final.

if nota >= 3.0:
    print("Aprobó")

¿Dentro o fuera?

if nota >= 3.0:
    print("Aprobó")
print("Fin")

No da error: "Fin" está fuera del if, así que se imprime siempre.

La sangría define la estructura del programa.

Provoca el IndentationError en vivo. La tercera tarjeta es la más importante: no hay error, pero el resultado cambia según dónde quede la línea.

elif

Cuando hay más de dos caminos

Concepto + live coding (1:15–1:30). elif y condiciones combinadas.

Varias opciones con elif

nota = 4.6
if nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobó")
else:
    print("Reprobó")

Python revisa las condiciones en orden y se detiene en la primera verdadera.

elif es la abreviatura de “else if”: “si no, entonces si…”. Puede haber tantos elif como se necesiten, pero un solo else al final.

El orden importa

Con nota = 4.6, ¿qué imprime este programa?

if nota >= 3.0:
    print("Aprobó")
elif nota >= 4.5:
    print("Excelente")
¿“Aprobó” o “Excelente”?
Clic para ver la respuesta
Imprime “Aprobó”. La primera condición ya es verdadera, así que Python nunca llega a revisar el elif. Las condiciones más exigentes van primero.
Deja que voten antes de revelar. Es un error lógico: no hay mensaje de error, pero el resultado está mal. Esos son los más difíciles de encontrar.

Condiciones combinadas

and

“y”

True solo si las dos condiciones son verdaderas.

or

“o”

True si al menos una es verdadera.

not

“no”

Invierte el valor: True pasa a False.

edad = 20
tiene_documento = True
if edad >= 18 and tiene_documento:
    print("Puede votar")

Pedir datos al usuario

input() siempre devuelve texto. Para comparar con números hay que convertirlo con int() o float().

Sin convertir 
edad = input("¿Cuántos años tienes? ")
if edad >= 18:
    print("Eres mayor de edad")
TypeError: '>=' not supported between
instances of 'str' and 'int'
Convirtiendo 
edad = int(input("¿Cuántos años tienes? "))
if edad >= 18:
    print("Eres mayor de edad")

Usa int() para enteros y float() para decimales, como una nota de 3.5.
