Entonces, ¿qué es programar?

Programar es escribir instrucciones precisas que un computador puede ejecutar para resolver un problema o hacer una tarea.

Tres palabras clave

InstruccionesPrecisiónProblema

Un programa es el resultado: una lista de instrucciones que el computador sigue en orden, de arriba hacia abajo.

Lee la definición en voz alta y subraya las tres palabras clave. Conecta con la sesión: hoy vamos a escribir nuestras primeras instrucciones en Python.

El computador es literal

Hace exactamente lo que le dices, no lo que quisiste decir.

  • No interpreta, no supone, no “entiende el contexto”.
  • Si la instrucción está mal escrita, no la entiende.
  • Una receta para alguien que no improvisa.
Actividad

La receta al pie de la letra. El grupo le dicta al monitor cómo preparar un sándwich. El monitor obedece exactamente lo que escucha. ¿Qué instrucciones faltaron?

En la actividad, sé muy literal: si dicen “pon la mantequilla en el pan” sin decir “abre el frasco”, no lo abras. Las risas ayudan a fijar la idea. Cierra preguntando qué instrucciones faltaron y por qué.

Algoritmo: la idea antes del código

Un algoritmo es una secuencia finita y ordenada de pasos para resolver un problema.

Ejemplo: calcular el promedio de mis notas

  1. Reunir todas las notas.
  2. Sumarlas.
  3. Contar cuántas notas hay.
  4. Dividir la suma entre la cantidad.
  5. Mostrar el resultado.
Insiste en que esto todavía es español, no código. Primero se piensa la solución; después se escribe en un lenguaje. Pregunta: ¿qué pasaría si invertimos los pasos 2 y 4?

Python 
notas = [3.0, 4.0, 3.5]
promedio = sum(notas) / len(notas)
print(promedio)   # 3.5
R 
notas <- c(3.0, 4.0, 3.5)
promedio <- mean(notas)
print(promedio)   # 3.5

El mismo algoritmo, dos lenguajes. No hay que entender cada símbolo todavía.

Solo para mostrar: no expliques la sintaxis. Señala que ambos programas siguen los mismos pasos de la diapositiva anterior. R ya trae mean(); en Python lo armamos con sum y len.

¿Qué es un lenguaje de programación?

Un idioma intermedio entre las personas y la máquina, con vocabulario (palabras reservadas) y gramática (sintaxis).

Entre más alto el nivel, más se parece a nuestro idioma y menos detalles de la máquina hay que manejar. Python y R son de alto nivel: por eso son buenos para empezar.

Muestra cómo leer el error de abajo hacia arriba. “Hola is not defined” significa que Python buscó una variable llamada Hola y no la encontró: faltaban las comillas.
