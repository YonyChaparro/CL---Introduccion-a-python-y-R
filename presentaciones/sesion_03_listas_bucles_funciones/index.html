Listas

Muchos datos en una sola variable

Concepto + live coding (0:15–0:40). Crear listas, posiciones desde 0, len() y append().

¿Por qué necesitamos listas?

Una variable por dato

Funciona con 4 notas… ¿y con 40?

nota1 = 3.5
nota2 = 4.2
nota3 = 2.8
nota4 = 4.9

Una lista

Todos los datos juntos, en orden.

notas = [3.5, 4.2, 2.8, 4.9]

Una lista guarda varios valores en orden dentro de una sola variable.

Pregunta cómo calcularían el promedio de 40 notas con 40 variables. La lista resuelve el problema de guardar; el bucle, que viene después, resuelve el de recorrer.

Crear una lista

Corchetes [ ] y elementos separados por comas

ciudades = ["Bogotá", "Medellín", "Cali"]
vacia = []

print(ciudades)
# ['Bogotá', 'Medellín', 'Cali']
  • Puede guardar números, textos o cualquier otro tipo de dato.
  • Una lista también puede empezar vacía e ir creciendo.

Contar y agregar

len() cuenta

Cuántos elementos tiene la lista.

notas = [3.5, 4.2, 2.8, 4.9]
print(len(notas))   # 4

.append() agrega

Pone un elemento nuevo al final.

notas.append(3.0)
print(notas)
# [3.5, 4.2, 2.8, 4.9, 3.0]
print(len(notas))   # 5

append se escribe después de la lista, con un punto: es una acción que la lista sabe hacer sobre sí misma.

La diferencia de escritura entre len(notas) y notas.append() confunde. No hace falta hablar de métodos: basta con decir que append es algo que “la lista hace”.

  1. 1La palabra for (“para cada”).

Acumuladores y range()

Sumar, contar y repetir

Es el tema que más cuesta del curso. Ve despacio y haz la ejecución a mano en el tablero.

El acumulador: sumar en cada vuelta

suma = 0                  # empieza en 0
for nota in notas:
    suma = suma + nota     # acumula

promedio = suma / len(notas)
print("Promedio:", promedio)
# Promedio: 3.85

El acumulador debe tener un valor antes del for.

Vueltanotasuma después
——0
13.50 + 3.5 = 3.5
24.23.5 + 4.2 = 7.7
32.87.7 + 2.8 = 10.5
44.910.5 + 4.9 = 15.4
Haz esta tabla en el tablero, vuelta por vuelta, antes de mostrar la de la diapositiva. Es la forma más efectiva de entender los acumuladores. Al final, 15.4 / 4 = 3.85.

Bucle + condicional: contar

¿Cuántos estudiantes aprobaron?

aprobados = 0
for nota in notas:
    if nota >= 3.0:
        aprobados = aprobados + 1

print("Aprobaron:", aprobados)
# Aprobaron: 3
  • El if va dentro del for: se revisa en cada vuelta.
  • El contador suma 1, no la nota.
  • Dos niveles de indentación: 4 y 8 espacios.
Aquí se juntan las sesiones 2 y 3. De las notas 3.5, 4.2, 2.8 y 4.9, solo 2.8 reprueba: aprobaron 3. Diferencia clave: el acumulador suma la nota; el contador suma 1.

¿Por qué crear funciones?

Si calculas el promedio de tres listas, ¿copias el mismo código tres veces?

Se escribe una vez

La solución queda guardada con un nombre.

Se usa muchas veces

Con datos distintos cada vez.

Se corrige en un lugar

Si hay un error, se arregla una sola vez.

Ya usaron funciones sin crearlas: print(), len(), type(). Hoy van a crear las suyas. Retoma la analogía de la receta de la sesión 1: ahora la receta tiene nombre.

Anatomía de una función

def1 calcular_promedio2(lista)3:

    for valor in lista:
        suma = suma + valor
    return4 suma / len(lista)

  1. 1def (“definir”) avisa que vamos a crear una función.
  2. 2El nombre: con las mismas reglas de las variables.
  3. 3El parámetro: el dato que recibe.
  4. 4return devuelve el resultado.
  5. 5La llamada: aquí se ejecuta de verdad.
Escribe la función en vivo, ejecútala y muestra que no pasa nada: definir no es ejecutar. Solo cuando la llamamos aparece el 4.0. Luego llámala con otra lista para mostrar la reutilización.

print muestra, return devuelve

print muestra

El resultado aparece en pantalla, pero no se puede guardar.

def saludar(nombre):
    print("Hola,", nombre)

r = saludar("Ana")   # Hola, Ana
print(r)              # None

return devuelve

El resultado se puede guardar y usar en otros cálculos.

def aplicar_iva(precio):
    return precio * 1.19

total = aplicar_iva(10000)
print(total)          # 11900.0

Si la función no tiene return, devuelve None: “nada”.

Es la confusión más común con funciones. Pregunta: ¿cómo calculo el total de una compra con saludar? No se puede, porque no devuelve nada. Con aplicar_iva sí: el resultado se guarda en total.
