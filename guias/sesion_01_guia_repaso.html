1¿Qué es programar?

Aunque no lo notemos, damos instrucciones a máquinas todos los días: programamos una alarma, escribimos una fórmula en Excel o creamos un filtro para el correo. Programar es hacer eso mismo, pero de forma más explícita y completa.

DefiniciónProgramar es escribir instrucciones precisas que un computador puede ejecutar para resolver un problema o hacer una tarea.
DefiniciónUn programa es el resultado: una lista de instrucciones que el computador sigue en orden, de arriba hacia abajo.

El computador es literal

El computador hace exactamente lo que le dices, no lo que quisiste decir. No supone, no adivina y no “entiende el contexto”. Si una instrucción está mal escrita o falta un paso, no lo completa por su cuenta: se detiene o hace algo distinto a lo que esperabas. Piensa en una receta escrita para alguien que nunca ha cocinado y que no improvisa.

Algoritmo: la idea antes del código

DefiniciónUn algoritmo es una secuencia finita y ordenada de pasos para resolver un problema.

Un algoritmo no depende de ningún lenguaje: se puede escribir en español. Por ejemplo, para calcular el promedio de tus notas:

  1. Reunir todas las notas.
  2. Sumarlas.
  3. Contar cuántas notas hay.
  4. Dividir la suma entre la cantidad.
  5. Mostrar el resultado.

Cuando ese algoritmo se escribe en un lenguaje de programación, se convierte en un programa. El camino completo es: problema → algoritmo → código → ejecución → resultado. El mismo algoritmo se puede escribir en Python o en R (todavía no tienes que entender cada símbolo):

Python 
notas = [3.0, 4.0, 3.5]
promedio = sum(notas) / len(notas)
print(promedio)   # 3.5
R 
notas <- c(3.0, 4.0, 3.5)
promedio <- mean(notas)
print(promedio)   # 3.5

Lenguajes de programación

DefiniciónUn lenguaje de programación es un idioma intermedio entre las personas y la máquina. Tiene un vocabulario (palabras reservadas, como print o if) y una gramática estricta llamada sintaxis.
NivelEjemploQuién lo entiende mejor
Lenguaje humano“Calcula el promedio de mis notas”Las personas
Alto nivel (Python, R)mean(notas)Las personas, y se traduce para la máquina
Bajo nivel (ensamblador)MOV EAX, [EBX]Más cerca de la máquina
Código máquina10110000 01100001El procesador

Python y R son lenguajes de alto nivel: se parecen más al idioma humano y nos dejan concentrarnos en el problema, no en los detalles del hardware.

Compilado o interpretado

CompiladoTraduce todo el programa antes de ejecutarlo, como traducir un libro completo antes de publicarlo. Ejemplos: C, Java.
InterpretadoLee y ejecuta línea por línea, como un intérprete en una conferencia. Ejemplos: Python, R.

Como Python es interpretado, escribes una línea y ves el resultado al instante. Por eso es ideal para aprender y para explorar datos.

¿Por qué Python y R?

  • Python es de propósito general (datos, web, automatización) y fue diseñado para ser legible. Lo usamos en las sesiones 1 a 4, en Google Colab.
  • R nació para la estadística y es muy fuerte en análisis y gráficos. Lo usamos en las sesiones 5 a 7, en Posit Cloud.
  • Ambos son gratuitos, tienen comunidades enormes y son muy usados en análisis de datos.

2Google Colab

Google Colab es un servicio gratuito de Google para escribir y ejecutar Python desde el navegador. No hay que instalar nada: solo necesitas una cuenta de Google.

DefiniciónUn notebook (cuaderno, archivo .ipynb) es un documento formado por celdas. Hay dos tipos: celdas de código, que se ejecutan, y celdas de texto, para títulos, notas y explicaciones.

Pasos básicos

  1. Abre el enlace del notebook con tu cuenta de Google.
  2. Ve a Archivo → Guardar una copia en Drive. Así trabajas sobre tu propia copia y tus cambios quedan guardados.
  3. Escribe en una celda de código.
  4. Ejecútala con Shift + Enter (o con el botón ▶ a la izquierda de la celda).
  5. La salida aparece justo debajo de la celda.

Para agregar celdas usa los botones + Código y + Texto de la parte superior.

OjoColab recuerda lo que ejecutaste, no lo que está escrito en pantalla. Si cambias una celda y no la vuelves a ejecutar, el cambio no cuenta. Si algo se comporta raro, usa Entorno de ejecución → Ejecutar todas para correr el notebook de arriba hacia abajo.

3Mostrar resultados con print()

DefiniciónUna función es una instrucción con nombre que hace una tarea. Se usa escribiendo su nombre seguido de paréntesis. print() es una función que muestra en pantalla lo que va entre sus paréntesis.
print("Hola, mundo")
print("Me llamo Ana")
print(2 + 3)
Hola, mundo
Me llamo Ana
5
  • El texto va entre comillas (dobles "…" o sencillas '…').
  • Los números van sin comillas: Python los calcula antes de mostrarlos.
  • Puedes mostrar varios valores separándolos con comas; Python pone un espacio entre ellos.
print("Ana", "tiene", 20, "años")   # los valores se separan con comas
Ana tiene 20 años

Comentarios

Todo lo que va después de # es un comentario: Python lo ignora. Sirve para dejar notas que explican el código, para ti o para otras personas.

4Variables

DefiniciónUna variable es como una caja con etiqueta: guarda un dato y lo puedes usar después por su nombre.
nombre = "Ana"
edad = 20
estatura = 1.65
print(nombre, "tiene", edad, "años")
Ana tiene 20 años

El signo = guarda, no compara

La instrucción edad = 20 se lee “guarda 20 en edad”. No es la igualdad de las matemáticas. Python primero calcula lo que está a la derecha del = y luego lo guarda en la variable de la izquierda. Por eso esto es válido:

edad = 20
edad = edad + 1     # calcula 20 + 1 y guarda 21 en edad
print(edad)
21

Una variable guarda un solo valor a la vez: al asignarle uno nuevo, el anterior se pierde.

Cómo nombrar una variable

nota_finalSíUsa guion bajo para separar palabras.
edad2SíPuede tener números, pero no al inicio.
2edadNoEmpieza con número.

nota-finalNoPython lo lee como una resta: nota menos final.
  • Usa nombres que digan qué guardan: precio es mejor que x.
  • Python distingue mayúsculas de minúsculas: Edad y edad son variables distintas.
  • Evita tildes y la ñ en los nombres de variables (en el texto entre comillas sí puedes usarlas).

6Operadores aritméticos

DefiniciónUn operador es un símbolo que hace una operación con uno o más valores. Una expresión es una combinación de valores, variables y operadores que Python calcula para obtener un resultado, como precio * cantidad.
SímboloOperaciónEjemploResultado
+Suma7 + 29
-Resta7 - 25
*Multiplicación7 * 214
/División7 / 23.5
//División entera (sin decimales)7 // 23
%Residuo de la división7 % 21
**Potencia7 ** 249
  • / siempre da un float, aunque la división sea exacta: 10 / 2 da 5.0.
  • % sirve, por ejemplo, para saber si un número es par: si n % 2 da 0, n es par.
  • Para potencias se usa **, no ^.

Orden de las operaciones

Python sigue el mismo orden que las matemáticas: primero potencias, luego multiplicaciones y divisiones, y al final sumas y restas. Los paréntesis cambian el orden.

print(2 + 3 * 4)       # primero 3 * 4
print((2 + 3) * 4)     # primero el paréntesis
14
20

Ejemplo: el total de una compra

precio = 12000
cantidad = 3
total = precio * cantidad
print("Total a pagar:", total)
print("Total con IVA:", total * 1.19)    # IVA del 19 %
Total a pagar: 36000
Total con IVA: 42840.0

Si cambias precio y vuelves a ejecutar la celda, el total se actualiza solo. Esa es una de las ventajas de usar variables.

Operadores con texto

Con texto, + une (concatena) y * repite:

print("Hola, " + "Ana")
print("3" + "4")      # texto + texto: los une, no los suma
print("Ja" * 3)
Hola, Ana
34
JaJaJa

7Leer errores sin miedo

Equivocarse es parte de programar, también para quienes llevan años haciéndolo. Un error (en inglés, bug) no es un fracaso: es el computador diciéndote dónde mirar. Buscar y corregir errores se llama depurar.

Anatomía de un mensaje de error

NameError                    Traceback (most recent call last)
----> 1 print(Hola)

NameError: name 'Hola' is not defined
  1. Qué tipo de error es: la primera palabra (NameError).
  2. Dónde: la flecha ----> marca la línea que falló.
  3. Por qué: la explicación, en la última línea.
ConsejoEmpieza siempre por la última línea del mensaje: ahí está la pista principal. Antes de corregir, intenta adivinar la causa.

Los tres errores más comunes

ErrorCódigo con errorQué significaCorrección
NameErrorprint(Hola)Python no conoce ese nombre. Aquí faltan las comillas, así que cree que Hola es una variable.print("Hola")
SyntaxErrorprint("Hola"Algo está mal escrito. Aquí falta cerrar el paréntesis: '(' was never closed.print("Hola")
TypeErroredad = "20"
edad + 1		La operación no sirve para ese tipo de dato: no se puede sumar texto con número.int(edad) + 1

Otros errores que vas a encontrar

  • Print("hola") → NameError: Python distingue mayúsculas, y la función se llama print.
  • print("Hola) → SyntaxError: unterminated string literal: falta cerrar las comillas.
  • 5 / 0 → ZeroDivisionError: division by zero: no se puede dividir entre cero.

Según la versión de Python, el texto de algunos mensajes puede cambiar un poco, pero el tipo de error es el mismo.

8Pedir datos con input()

Definicióninput() muestra un mensaje, espera a que el usuario escriba algo y presione Enter, y devuelve lo que escribió para que lo guardes en una variable.
nombre = input("¿Cómo te llamas? ")
print("Hola,", nombre)
¿Cómo te llamas? Ana
Hola, Ana
Ojoinput() siempre devuelve texto (str), aunque el usuario escriba un número. Para hacer cálculos, conviértelo primero con int() o float().
edad = int(input("¿Cuántos años tienes? "))
print("El próximo año tendrás", edad + 1)
¿Cuántos años tienes? 20
El próximo año tendrás 21

Tres ideas clave

  • Un programa es una lista de instrucciones que se ejecuta en orden.
  • Las variables guardan datos, y cada dato tiene un tipo.
  • Los errores son pistas: leerlos es parte de programar.
