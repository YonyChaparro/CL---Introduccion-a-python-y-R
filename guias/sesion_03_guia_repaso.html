1Listas

Con lo que sabemos hasta ahora, cada dato necesita su propia variable. Funciona con 4 notas, pero ¿y con 40? La solución es guardarlas todas juntas.

DefiniciónUna lista guarda varios valores en orden dentro de una sola variable. Cada valor de la lista se llama elemento.
Una variable por dato 
nota1 = 3.5
nota2 = 4.2
nota3 = 2.8
nota4 = 4.9
Una lista 
notas = [3.5, 4.2, 2.8, 4.9]

Crear una lista

Se escribe con corchetes [ ] y los elementos van separados por comas.

notas = [3.5, 4.2, 2.8, 4.9]
ciudades = ["Bogotá", "Medellín", "Cali"]
vacia = []

print(ciudades)
print(vacia)
['Bogotá', 'Medellín', 'Cali']
[]
  • Puede guardar números, textos o cualquier otro tipo de dato.
  • También puede empezar vacía e ir creciendo.
  • print() muestra la lista completa, con corchetes y comillas.

3Contar y agregar: len() y append()

len() cuenta: cuántos elementos tiene la lista. 
notas = [3.5, 4.2, 2.8, 4.9]
print(len(notas))
4
.append() agrega: pone un elemento al final. 
notas = [3.5, 4.2, 2.8, 4.9]
notas.append(3.0)
print(notas)
print(len(notas))
[3.5, 4.2, 2.8, 4.9, 3.0]
5

Fíjate en cómo se escribe cada una: len(notas) lleva la lista entre paréntesis, mientras que append se escribe después de la lista, con un punto: es una acción que la lista sabe hacer sobre sí misma.

4El bucle for

DefiniciónUn bucle repite un bloque de código. El bucle for lo repite una vez por cada elemento de una lista. Cada repetición se llama vuelta (o iteración).
notas = [3.5, 4.2, 2.8, 4.9]
for nota in notas:
    print("Nota:", nota)
Nota: 3.5
Nota: 4.2
Nota: 2.8
Nota: 4.9

Se lee casi como en español: “para cada nota en notas, imprime la nota”.

Anatomía de un for

  1. La palabra for (“para cada”).
  2. Una variable que toma cada valor, uno a la vez. El nombre lo eliges tú.
  3. La lista que se recorre, después de in.
  4. Los dos puntos y, debajo, el bloque indentado que se repite. Funcionan igual que en el if.

¿Cómo se ejecuta?

En cada vuelta, la variable nota cambia de valor. Cuando ya no quedan elementos, el programa sigue con la línea que hay después del bloque.

5Acumuladores y contadores

DefiniciónUn acumulador es una variable que va guardando un total: en cada vuelta del bucle le sumamos algo.

Tiene tres pasos: crear el acumulador antes del for, actualizarlo dentro y usarlo después.

notas = [3.5, 4.2, 2.8, 4.9]
suma = 0                      # 1. empieza en 0, antes del for
for nota in notas:
    suma = suma + nota        # 2. acumula en cada vuelta

promedio = suma / len(notas)  # 3. se usa al final
print("Promedio:", promedio)
Promedio: 3.85

Bucle + condicional: contar

Aquí se juntan las sesiones 2 y 3. ¿Cuántos estudiantes aprobaron?

7Funciones

Ya usaste funciones sin crearlas: print(), len(), type(). Ahora vas a crear las tuyas. Si calculas el promedio de tres listas, ¿copias el mismo código tres veces?

DefiniciónUna función es como una receta con nombre: un bloque de código que se escribe una vez y se puede usar muchas veces.
  • Se escribe una vez: la solución queda guardada con un nombre.
  • Se usa muchas veces: con datos distintos cada vez.
  • Se corrige en un lugar: si hay un error, se arregla una sola vez.

Anatomía de una función

def calcular_promedio(lista):
    suma = 0
    for valor in lista:
        suma = suma + valor
    return suma / len(lista)

print(calcular_promedio([3.5, 4.0, 4.5]))
print(calcular_promedio([2.0, 3.0]))
4.0
2.5
ParteEn el ejemploQué hace
defdef“Definir”: avisa que vamos a crear una función.
Nombrecalcular_promedioSigue las mismas reglas que los nombres de variables.
ParámetrolistaEl dato que la función recibe.
returnreturn suma / len(lista)Devuelve el resultado a quien llamó la función.
Llamadacalcular_promedio([3.5, 4.0, 4.5])Aquí se ejecuta de verdad. El valor que le pasamos se llama argumento.
OjoDefinir no es ejecutar. Si escribes el def y ejecutas la celda, no pasa nada visible: Python solo guarda la receta. El código corre cuando llamas a la función.

print muestra, return devuelve

Es la confusión más común con las funciones. print pone el resultado en pantalla, pero no lo entrega. return lo entrega para que puedas guardarlo y usarlo en otros cálculos.

print muestra 
def saludar(nombre):
    print("Hola,", nombre)

r = saludar("Ana")
print(r)
Hola, Ana
None
return devuelve 
def aplicar_iva(precio):
    return precio * 1.19

total = aplicar_iva(10000)
print(total)
11900.0

Si la función no tiene return, devuelve None, que significa “nada”.

Errores sin mensaje

Estos no muestran ningún error, pero el resultado está mal:

  • suma = 0 dentro del for: el acumulador se reinicia en cada vuelta.
  • print en lugar de return: ves el resultado, pero la función devuelve None y no puedes usarlo.
  • notas = notas.append(3.0): append cambia la lista y devuelve None, así que pierdes tu lista. Basta con notas.append(3.0).

Según la versión de Python, el texto de algunos mensajes puede cambiar un poco, pero el tipo de error es el mismo.

Tres ideas clave

  • Las listas guardan varios datos en orden; en Python la primera posición es 0.
  • El for repite una acción para cada elemento.
  • Las funciones empaquetan una solución para reutilizarla.
