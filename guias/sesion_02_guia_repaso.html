1Comparaciones

Hasta ahora, nuestros programas hacían siempre lo mismo, de arriba hacia abajo. Para que un programa pueda decidir, primero necesita hacerse preguntas que se respondan con sí o no.

DefiniciónUna comparación es una pregunta sobre dos valores. Su resultado siempre es un bool: True (verdadero) o False (falso).
nota = 3.5
print(nota >= 3.0)
print(nota == 5)
True
False

Los seis operadores de comparación

SímboloPreguntaCon nota = 3.5Resultado
==¿Es igual?nota == 5False
!=¿Es distinto?nota != 5True
>¿Es mayor?nota > 4False
<¿Es menor?nota < 4True
>=¿Es mayor o igual?nota >= 3.0True
<=¿Es menor o igual?nota <= 3.5True
  • >= y <= se escriben en ese orden: => no existe en Python.
  • True y False llevan mayúscula inicial y no van entre comillas.

= guarda, == compara

Es la confusión más común de esta sesión. Un solo = guarda un valor en una variable. Dos signos == preguntan si dos valores son iguales.

= asigna: “guarda 3.5 en nota” 
nota = 3.5
print(nota)
3.5
== pregunta: “¿nota es igual a 3.5?” 
nota = 3.5
print(nota == 3.5)

También se puede comparar texto

print("Ana" == "Ana")
print("Ana" == "ana")   # distingue mayúsculas y minúsculas
print("5" == 5)         # texto y número no son iguales

2Tomar un camino u otro: if y else

DefiniciónUn condicional es una instrucción que ejecuta un bloque de código solo si se cumple una condición. Una condición es cualquier expresión que da True o False.

Con if (“si”) y else (“si no”) el programa elige entre dos caminos. Un diagrama de flujo dibuja esos caminos. El camino resaltado en azul es el que toma el programa con nota = 2.8:

nota = 2.8
if nota >= 3.0:
    print("Aprobó")
else:
    print("Reprobó")
Reprobó

Como 2.8 no es mayor o igual a 3.0, la condición da False y el programa toma el camino del else.

Anatomía de un if

  1. La palabra if.
  2. La condición: algo que da True o False.
  3. Los dos puntos : al final de la línea. Se olvidan mucho.
  4. La indentación: 4 espacios que marcan qué va dentro del if.

El else no lleva condición, pero sí lleva dos puntos. Además, es opcional: si no lo escribes y la condición da False, el programa simplemente sigue con lo que viene después.

nota = 4.0
if nota >= 3.0:
    print("Aprobó")
print("Fin")
Aprobó
Fin
ConsejoPrueba el programa con nota = 3.0 exacto. Con >= aprueba; con > reprueba. Un solo símbolo cambia el resultado, así que elige el operador con cuidado.

3La indentación no es decoración

DefiniciónLa indentación (o sangría) son los espacios al inicio de una línea. En Python define la estructura del programa: las líneas con la misma indentación debajo del if forman un bloque, y ese bloque solo se ejecuta si la condición se cumple.

Se usan 4 espacios. En Colab, la tecla Tab los inserta por ti, y después de escribir los dos puntos y presionar Enter, la indentación aparece sola.

¿Dentro o fuera?

Estos dos programas solo se diferencian en la indentación de la última línea, y no hacen lo mismo:

“Fin” dentro del if 
nota = 2.0
if nota >= 3.0:
    print("Aprobó")
    print("Fin")
(no imprime nada)
“Fin” fuera del if 
nota = 2.0
if nota >= 3.0:
    print("Aprobó")
print("Fin")
Fin

Ninguno da error. La condición es False en los dos casos, pero a la derecha "Fin" está fuera del bloque, así que se imprime siempre.

Si falta la indentación

nota = 3.5
if nota >= 3.0:
print("Aprobó")
IndentationError: expected an indented block after 'if' statement on line 2

Python espera un bloque indentado después de los dos puntos, y no lo encuentra.

4Varias opciones con elif

Definiciónelif es la abreviatura de “else if” (“si no, entonces si…”). Permite revisar otra condición cuando la anterior no se cumplió. Python revisa las condiciones en orden y se detiene en la primera verdadera.
nota = 4.6
if nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobó")
else:
    print("Reprobó")
Excelente
  • Empieza con un if.
  • Puede tener tantos elif como necesites, cada uno con su condición.
  • Termina, si quieres, con un solo else, sin condición.
  • Solo se ejecuta un camino.

Cómo lo recorre Python

Este es el recorrido del mismo programa con nota = 3.4:

PasoLíneaResultadoQué hace Python
1if nota >= 4.5:FalseSalta su bloque y sigue a la siguiente condición.
2elif nota >= 3.0:TrueImprime Aprobó y se detiene.
3else:—Ni siquiera lo revisa.

El orden importa

Con nota = 4.6, ¿qué imprime este programa?

nota = 4.6
if nota >= 3.0:
    print("Aprobó")
elif nota >= 4.5:
    print("Excelente")
Aprobó
OjoEsto es un error lógico: no aparece ningún mensaje de error, pero el resultado está mal. La primera condición ya es verdadera, así que Python nunca llega a revisar el elif. Por eso las condiciones más exigentes van primero.

elif no es lo mismo que otro if

Con varios if seguidos, Python revisa todos, y puede ejecutarse más de un camino:

Con elif: un solo camino 
nota = 4.6
if nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobó")
Excelente
Con dos if: se revisan ambos 
nota = 4.6
if nota >= 4.5:
    print("Excelente")
if nota >= 3.0:
    print("Aprobó")
Excelente
Aprobó

5Combinar condiciones: and, or, not

DefiniciónLos operadores lógicos combinan o invierten condiciones. El resultado también es True o False.
OperadorSe leeDa True cuando…Con edad = 20 y tiene_documento = FalseResultado
and“y”Las dos condiciones son verdaderas.edad >= 18 and tiene_documentoFalse
or“o”Al menos una es verdadera.edad >= 18 or tiene_documentoTrue
not“no”La condición es falsa: invierte el valor.not tiene_documentoTrue

Ejemplo: ¿puede votar?

edad = 20
tiene_documento = True
if edad >= 18 and tiene_documento:
    print("Puede votar")
else:
    print("No puede votar")
Puede votar

Para votar se necesitan las dos cosas, por eso usamos and. Si usáramos or, alguien de 15 años con documento podría votar:

Personaedad >= 18tiene_documentoandor
20 años, con documentoTrueTrueTrueTrue
20 años, sin documentoTrueFalseFalseTrue
15 años, con documentoFalseTrueFalseTrue
15 años, sin documentoFalseFalseFalseFalse

Invertir con not

tiene_documento = False
if not tiene_documento:
    print("Recuerda traer tu documento")
Recuerda traer tu documento
OjoCada lado de and y or debe ser una condición completa. edad >= 18 and <= 25 da SyntaxError: se escribe edad >= 18 and edad <= 25. Y dia == "sábado" or "domingo" no da error, pero siempre se cumple: se escribe dia == "sábado" or dia == "domingo".

6Decidir con datos del usuario: input()

En la sesión 1 vimos que input() siempre devuelve texto. Para comparar con números, primero hay que convertir ese texto.

Sin convertir: error

edad = input("¿Cuántos años tienes? ")
if edad >= 18:
    print("Eres mayor de edad")
TypeError: '>=' not supported between instances of 'str' and 'int'

El mensaje dice que no se puede usar >= entre un texto (str) y un entero (int).

Convirtiendo: funciona

edad = int(input("¿Cuántos años tienes? "))
if edad >= 18:
    print("Eres mayor de edad")
¿Cuántos años tienes? 20
Eres mayor de edad

Usa int() para enteros y float() para decimales, como una nota de 3.5:

nota = float(input("¿Cuál es tu nota? "))
if nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobó")
else:
    print("Reprobó")
¿Cuál es tu nota? 3.5
Aprobó
OjoSi el usuario escribe 3.5 y usas int(input(...)), Python responde con ValueError, porque ese texto no es un entero. Para notas, usa float().

7Errores frecuentes

Recuerda lo que vimos en la sesión 1: empieza por la última línea del mensaje, que es donde está la pista principal.

Error y qué significaCódigo con errorCorrección
SyntaxError
Faltan los dos puntos: expected ':'.		nota = 3.5 if nota >= 3.0 print("Aprobó")nota = 3.5 if nota >= 3.0: print("Aprobó")
SyntaxError
Usaste =, que guarda, en lugar de ==, que compara.		nota = 3.5 if nota = 3.5: print("Igual")nota = 3.5 if nota == 3.5: print("Igual")
IndentationError
Falta la sangría del bloque.		nota = 3.5 if nota >= 3.0: print("Aprobó")nota = 3.5 if nota >= 3.0: print("Aprobó")
TypeError
Se está comparando texto con un número.		edad = input("Edad: ") if edad >= 18: print("Mayor")edad = int(input("Edad: ")) if edad >= 18: print("Mayor")

Otros errores que vas a encontrar

  • else if nota >= 3.0: → SyntaxError: en Python se escribe elif.
  • else nota < 3.0: → SyntaxError: el else no lleva condición.
  • If nota >= 3.0: → SyntaxError: Python distingue mayúsculas; se escribe if.
  • print(true) → NameError: se escribe True, con mayúscula.
  • Sin mensaje de error: condiciones en mal orden o and en lugar de or. El programa corre, pero el resultado está mal. Por eso conviene probarlo con varios valores.

Según la versión de Python, el texto de algunos mensajes puede cambiar un poco, pero el tipo de error es el mismo.

Tres ideas clave

  • Una condición siempre se evalúa como True o False.
  • if / elif / else permite que el programa tome caminos distintos.
  • En Python la indentación no es decoración: define la estructura.
